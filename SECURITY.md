# Equinox Core (EQX) — Incentivized Testnet Bug Bounty & Security Policy

EquinoxCore-Foundation invites Rust developers, node runners, and security researchers to audit `equinox-core` (Chain ID: 9333) and `Equinox-Super-Wallet`.

## Bounty Reward Tiers (Paid Automatically via Mainnet Genesis Snapshot)
- **Critical (10,000 - 25,000 EQX):** Consensus split, unauthorized supply minting beyond 21M cap, UTXO double-spend, or private key leak.
- **High (2,500 - 10,000 EQX):** P2P TCP DoS crash, RPC memory exhaustion, or AMM reserve manipulation.
- **Medium / Low (250 - 2,500 EQX):** Edge-case RPC bugs, UI/UX enhancements, and multi-OS build scripts.

## How to Submit & Claim
Open an Issue or Pull Request on this repository and include your Equinox (`E...`) wallet address. All verified addresses are added to `mainnet_airdrop_allocations.json` for automatic block-0 Mainnet distribution.
